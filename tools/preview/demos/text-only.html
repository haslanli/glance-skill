/glance

People get logged out after paying by card because the payment page sends them back to www.shop.example.com, and the login cookie only works on shop.example.com.

Why it happens
  • The session cookie has no Domain attribute (auth/session.ts:41), so it only goes to shop.example.com
  • The return URL in the payment dashboard is https://www.shop.example.com/checkout/done
  • www. is served by the same app with no redirect, so the page loads without the cookie
  • Apple Pay isn't affected: it returns through a JavaScript callback on the same page
Fix
  1. Change the return URL to https://shop.example.com/checkout/done
  2. Optional: set Domain=shop.example.com on the cookie and redirect www. to the bare domain
